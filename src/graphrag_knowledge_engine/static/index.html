How it works
⬡ Dense Retrieval
Feature-hashing embeddings stored in ChromaDB. Finds semantically similar passages even without exact keyword matches.
⬡ BM25 Retrieval
Okapi BM25 for exact terms, identifiers, version strings, and package names where semantic similarity fails.
⬡ Graph Expansion
Knowledge graph BFS from query entities. Discovers evidence across multi-hop relationships.
⬡ RRF Fusion
Reciprocal Rank Fusion combines all retrieval legs without requiring comparable score scales.
